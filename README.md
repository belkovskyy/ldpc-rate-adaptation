# ldpc-rate-adaptation

Адаптация скорости LDPC-кода для информационной реконсиляции в квантовом
распределении ключей (QKD).

По телеметрии квантового канала нужно на каждом кадре выбрать параметры кода
`{R, s, p}` так, чтобы коррекция ошибок прошла, а раскрытой информации было
минимально — то есть скорость кода `R` максимально возможной при текущем уровне
ошибок QBER.

## Задача

В QKD стороны исправляют расхождения в сыром ключе LDPC-кодом. Чем выше ошибки
канала (QBER), тем ниже приходится брать скорость кода `R` — иначе коррекция не
сойдётся; но чем ниже `R`, тем больше раскрывается бит. Оптимум — взять
**максимальный `R`**, при котором коррекция ещё проходит.

Данные — телеметрия кадров (`block_id, frame_idx, E_mu_Z, E_mu_Z_est, synErr,
N_EC_rounds, maintenance_flag`). Нужно для целевого окна из 2000 кадров выдать
`{E_mu_Z, R, s, p}`. Данные в репозиторий не выкладываются.

## Подход

Двухступенчатый пайплайн: прогноз QBER → политика выбора кода.

- **Прогноз QBER (квантильная регрессия).** LightGBM с `objective=quantile`
  оценивает медиану (`alpha=0.5`) и верхний квантиль (`alpha=0.8`) уровня ошибок.
  Признаки — лаги и скользящие статистики QBER и физпараметров канала.
  Гиперпараметры подбираются Optuna. Валидация — `TimeSeriesSplit` с зазором.
- **Верхний квантиль как запас.** Прогноз `q0.8` даёт консервативную оценку QBER
  для fail-safe: лучше взять скорость чуть ниже, чем не пройти коррекцию.
- **Политика `{R, s, p}`.** По оценке QBER берётся целевая эффективная скорость
  `1 - f_ec·h2(QBER)` и выбирается максимальный допустимый `R` из сетки, при котором
  puncturing/shortening (`s + p = d`) укладывается в границы. EMA сглаживает QBER
  по истории кадров.

## Метрика

Прогноз QBER валидируется по MAE на `TimeSeriesSplit` (QBER мал, порядка 0.01–0.08,
поэтому ошибка измеряется в тысячных). Итоговое качество определяется политикой
`{R, s, p}`: чем выше выбранная скорость кода при успешно проходящей коррекции,
тем меньше раскрыто бит.

## Структура

```
notebooks/ldpc_rate_adaptation.ipynb   полный пайплайн: признаки, квантильная
                                       регрессия QBER, суррогат фейла, политика
src/
  features.py   лаги и скользящие статистики по QBER
  qber.py       квантильная регрессия LightGBM + Optuna, TimeSeriesSplit с gap
  policy.py     выбор {R, s, p}: бинарная энтропия, максимизация R, EMA
```

Стек: LightGBM, Optuna, scikit-learn, pandas, numpy. Обучение на CPU.
